# ภารกิจต่างประเทศ ฝูง.602 บน.6 · ปีงบประมาณ 70

ตารางรวมภารกิจต่างประเทศ ปฏิทินรายเดือน และไทม์ไลน์ หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลอยู่ใน Google Sheets และเชื่อมกันผ่าน Google Apps Script ซึ่งเป็นรูปแบบเดียวกับ [3M Calendar](https://github.com/rtaf602/3mcalendar)

- หน้าเว็บ: https://rtaf602.github.io/overseas-mission/
- เข้าใช้งานด้วยชื่อผู้ใช้งานและรหัสเปิดใช้งาน ระบบตรวจรหัสที่ฝั่ง Google ใส่ครั้งหนึ่งใช้ได้ 1 ชั่วโมง
- หลายคนเปิดดูและแก้พร้อมกันได้ ทุกหน้าจะเห็นการแก้ไขของคนอื่นภายในไม่กี่วินาที

## ติดตั้งครั้งแรก (ประมาณ 10 นาที)

ใช้บัญชี Google ที่เป็นเจ้าของ หรือมีสิทธิ์แก้ไข ทั้งไฟล์ต้นทาง ไฟล์แสดงผล และโฟลเดอร์ Backup

1. เปิดไฟล์ **รวมภารกิจต่างประเทศ ปีงบ70_ต้นทาง** แล้วไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. (ครั้งแรกเท่านั้น) กด **+ > Script** ตั้งชื่อว่า `Seed` แล้ววางเนื้อหาจากไฟล์ `Seed.gs` ที่ได้รับแยกต่างหาก ซึ่งเป็นข้อมูลเริ่มต้นปีงบ 70 (12 ภารกิจ)
4. **ตั้งรหัส** (ห้ามใส่รหัสลง GitHub): ใน `Code.gs` หาฟังก์ชัน `setCodes` แล้วพิมพ์รหัสลงในเครื่องหมาย `''`
   - `ACCESS_CODE` คือรหัสเปิดใช้งานหน้าเว็บที่ทุกคนใช้
   - `ADMIN_CODE` คือรหัส admin ที่ใช้เฉพาะตอนวางลิงก์ไฟล์ปีงบใหม่
   - กด 💾 บันทึก เลือกฟังก์ชัน **setCodes** ที่แถบด้านบน แล้วกด **Run**
   - Google จะขอสิทธิ์ ให้กด Review permissions > เลือกบัญชี > Advanced > Go to … (unsafe) > Allow
   - เมื่อขึ้นว่า "ตั้งรหัสเปิดใช้งานแล้ว" และ "ตั้งรหัส admin แล้ว" ให้**ลบรหัสทั้งสองออกจากโค้ด**ให้เหลือ `''` แล้วกดบันทึก ระบบเก็บรหัสไว้ฝั่ง Google แล้ว
5. เลือกฟังก์ชัน **setup** แล้วกด **Run**
   - รอจนบันทึกการทำงานขึ้นว่า "ปีงบ 70: นำเข้าข้อมูลเริ่มต้น 12 ภารกิจ" และ "ตั้งค่าเสร็จแล้ว" ตอนนี้ไฟล์ต้นทางจะมีแท็บข้อมูล และไฟล์แสดงผลจะมีตาราง
   - (ถ้า Seed.gs มีข้อมูลปีงบย้อนหลังที่ยังไม่มีไฟล์ ระบบจะสร้างไฟล์ต้นทาง/แสดงผลของปีนั้นให้เองในโฟลเดอร์เดียวกับไฟล์ปีงบ 70)
6. กด **Deploy > New deployment** > รูปเฟือง แล้วเลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** ซึ่งลงท้ายด้วย `/exec`
7. ใส่ URL ในไฟล์ [`config.js`](config.js) ของ repo นี้ (`apiUrl: 'https://script.google.com/macros/s/…/exec'`) แล้ว commit
8. ลบไฟล์ `Seed` ใน Apps Script ทิ้งได้ เพราะนำเข้าข้อมูลแล้ว
9. เปิด GitHub Pages: ไปที่ repo > **Settings > Pages** > Source: **Deploy from a branch** > Branch: **main** / **(root)** > Save
10. เปิด https://rtaf602.github.io/overseas-mission/ แล้วใส่ชื่อและรหัสเปิดใช้งาน

## ปีงบประมาณ

ปีงบ N คือ 1 ต.ค.(N-1) – 30 ก.ย.N แต่ละปีงบมีไฟล์ต้นทางและไฟล์แสดงผลของตัวเอง

### ภารกิจอยู่ปีงบไหน (ระบบจัดให้เองตามวันปฏิบัติภารกิจ)

| กรณี | ระบบบันทึกไว้ที่ |
|---|---|
| วันปฏิบัติภารกิจอยู่ในปีงบเดียว | ปีงบนั้น ไม่ว่าจะกรอกจากตารางปีงบไหน |
| ปฏิบัติภารกิจจริงข้ามปีงบ เช่น 29 ก.ย.–2 ต.ค. | ทั้ง 2 ปีงบ เป็นภารกิจเดียวกัน แก้ที่ตารางไหนก็ตรงกันทั้งสองไฟล์ และในตารางจะมีป้าย "อยู่ทั้งปีงบ 70 และ 71" |
| มีช่วงวัน "หรือ" ที่คร่อมปีงบ | ปีงบก่อนหน้า และเมื่อแก้จนเหลือช่วงเดียว ระบบจะย้ายไปปีงบที่ถูกต้องเอง |
| ปีงบนั้นยังไม่ได้วางลิงก์ | ปีงบล่าสุดที่มีลิงก์ไปก่อน มีป้ายสีแดง "รอย้ายไปปีงบ …" และระบบจะย้ายให้เองทันทีที่วางลิงก์ ระหว่างนี้ยังใช้งานได้ตามปกติ |
| ยังไม่ใส่วันที่ | ปีงบของตารางที่กดเพิ่ม |

ทุกครั้งที่ระบบย้ายภารกิจ จะมีข้อความแจ้งบนหน้าเว็บ และบันทึกไว้ในประวัติการแก้ไขของทั้งสองปีงบ

### ขึ้นปีงบใหม่ (admin)

1. ตั้งแต่ 1 ส.ค. หน้าเว็บจะขึ้นแถบเตือน "อีก … วันจะขึ้นปีงบ …" แถบจะเป็นสีแดงในวันที่ 30 ก.ย.
2. ถ้าถึง 1 ต.ค. แล้วยังไม่วางลิงก์ แถบจะเป็นสีแดง ระหว่างนี้ยังแก้ไขได้ แต่ข้อมูลจะบันทึกลงชีทปีงบเก่าไว้ก่อน และย้ายให้เองเมื่อวางลิงก์
3. สร้าง Google Sheets ว่าง 2 ไฟล์ เช่น `รวมภารกิจต่างประเทศ ปีงบ71_ต้นทาง` และ `รวมภารกิจต่างประเทศ ปีงบ71_แสดงผล` โดยบัญชีที่ Deploy สคริปต์ต้องแก้ไขทั้ง 2 ไฟล์ได้
4. กดปุ่มบนแถบเตือน หรือปุ่ม **ไฟล์ข้อมูล** มุมขวาบน วางลิงก์ทั้ง 2 ไฟล์ ใส่**รหัส admin** แล้วกด **บันทึกลิงก์** ระบบจะตรวจว่าเปิดไฟล์ได้ สร้างแท็บให้เอง และย้ายภารกิจที่รออยู่ไปไฟล์ใหม่ ไม่ต้องแก้โค้ดหรือ Deploy ใหม่

### ดูย้อนหลัง

- ตั้งแต่ 1 ต.ค. ตารางจะเปิดที่ปีงบใหม่เอง ส่วนปีงบก่อนหน้าเลือกดูได้ที่ตัวเลือกปีงบบนแถบสรุปเหนือตาราง (ตัวเลือกนี้ขึ้นเมื่อมีตั้งแต่ 2 ปีงบ)
- ตารางของปีงบก่อนหน้าแก้ไขได้เหมือนปีปัจจุบัน และใช้ PREVIEW ส่งออก PDF/Excel ฉบับที่บันทึก และประวัติการแก้ไขของปีงบนั้นได้
- ไทม์ไลน์และปฏิทินรายเดือนแสดงภารกิจของทุกปีงบรวมกัน ภารกิจที่อยู่คนละปีงบกับตารางจะมีเลขปีงบนำหน้า เช่น `70/12` คือภารกิจที่ 12 ของปีงบ 70

## วันหยุดราชการ

- ที่ ไทม์ไลน์ > ปฏิทินรายเดือน คลิกหัววันที่เพื่อตั้งเป็นวันหยุด แก้ชื่อวันหยุด หรือยกเลิกวันหยุด แล้วทุกคนจะเห็นเหมือนกัน
- วันหยุดใช้ร่วมกันทุกปีงบ และเก็บไว้ในแท็บ `holidays` ของไฟล์ต้นทางปีงบ 70 ทุกการแก้ไขบันทึกในประวัติการแก้ไข
- ถ้ายังไม่เคยแก้ ระบบจะใช้รายการวันหยุดปี 2569–2570 ที่ใส่ไว้ในหน้าเว็บ

## แก้โค้ดฝั่ง Google ภายหลัง

วางโค้ดใหม่ใน Apps Script แล้วไปที่ **Deploy > Manage deployments** > ✏️ > Version: **New version** > Deploy
URL เดิมยังใช้ได้ จึงไม่ต้องแก้ config.js

## งานดูแลที่ทำได้ใน Apps Script

| ฟังก์ชัน | ใช้เมื่อ |
|---|---|
| `setCodes` | เปลี่ยนรหัสเปิดใช้งานหรือรหัส admin: พิมพ์รหัสใหม่เฉพาะช่องที่จะเปลี่ยน กด Run แล้วลบรหัสออกจากโค้ด (คนที่เข้าอยู่แล้วใช้ต่อได้จนครบ 1 ชั่วโมง) |
| `renderNow` | วาดไฟล์แสดงผลของทุกปีงบใหม่ทันที |

ตัวตั้งเวลาที่ `setup` สร้างให้มีดังนี้
- วาดไฟล์แสดงผลใหม่ทุก 1 นาที ถ้ามีการแก้ไขที่ยังไม่ได้วาด (ปกติหน้าเว็บสั่งวาดเองหลังแก้ไขประมาณ 4 วินาที)
- ประวัติการแก้ไขเก็บไว้ตลอด ไม่ลบ (แต่ละปีงบอยู่ในไฟล์ของตัวเอง) ถ้าต้องการกำหนดระยะเก็บ ให้ตั้ง `LOG_DAYS` ใน Code.gs เป็นจำนวนวัน แล้วรัน setup ใหม่
