# ภารกิจต่างประเทศ ฝูง.602 บน.6 · ปีงบประมาณ 70

ตารางรวมภารกิจต่างประเทศ ปฏิทินรายเดือน และไทม์ไลน์ หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลอยู่ใน Google Sheets และเชื่อมกันผ่าน Google Apps Script ซึ่งเป็นรูปแบบเดียวกับ [3M Calendar](https://github.com/rtaf602/3mcalendar)

- หน้าเว็บ: https://rtaf602.github.io/overseas-mission/
- เข้าใช้งานด้วยชื่อผู้ใช้งานและรหัสเปิดใช้งาน ระบบตรวจรหัสที่ฝั่ง Google ใส่ครั้งหนึ่งใช้ได้ 1 ชั่วโมง
- หลายคนเปิดดูและแก้พร้อมกันได้ ทุกหน้าจะเห็นการแก้ไขของคนอื่นภายในไม่กี่วินาที

## ติดตั้งครั้งแรก (ประมาณ 10 นาที)

ใช้บัญชี Google ที่เป็นเจ้าของ หรือมีสิทธิ์แก้ไข ทั้งไฟล์ต้นทาง ไฟล์แสดงผล และโฟลเดอร์ Backup

1. เปิดไฟล์ **รวมภารกิจต่างประเทศ ปีงบ70_ต้นทาง** แล้วไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. (ครั้งแรกเท่านั้น) กด **+ > Script** ตั้งชื่อว่า `Seed` แล้ววางเนื้อหาจากไฟล์ `Seed.gs` ที่ได้รับแยกต่างหาก ซึ่งเป็นข้อมูลแผน 12 ภารกิจปัจจุบัน
4. กด 💾 บันทึก เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **Run**
   - Google จะขอสิทธิ์ ให้กด Review permissions > เลือกบัญชี > Advanced > Go to … (unsafe) > Allow
   - รอจนบันทึกการทำงานขึ้นว่า "นำเข้าข้อมูลเริ่มต้น 12 ภารกิจ" และ "ตั้งค่าเสร็จแล้ว" ตอนนี้ไฟล์ต้นทางจะมีแท็บข้อมูล และไฟล์แสดงผลจะมีตาราง
5. กด **Deploy > New deployment** > รูปเฟือง แล้วเลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** ซึ่งลงท้ายด้วย `/exec`
6. ใส่ URL ในไฟล์ [`config.js`](config.js) ของ repo นี้ (`apiUrl: 'https://script.google.com/macros/s/…/exec'`) แล้ว commit
7. ลบไฟล์ `Seed` ใน Apps Script ทิ้งได้ เพราะนำเข้าข้อมูลแล้ว
8. เปิด GitHub Pages: ไปที่ repo > **Settings > Pages** > Source: **Deploy from a branch** > Branch: **main** / **(root)** > Save
9. เปิด https://rtaf602.github.io/overseas-mission/ แล้วใส่ชื่อและรหัสเปิดใช้งาน

## ขึ้นปีงบประมาณใหม่

แต่ละปีงบมีไฟล์ต้นทางและไฟล์แสดงผลของตัวเอง ปีงบ N คือ 1 ต.ค.(N-1) – 30 ก.ย.N

1. ตั้งแต่ 1 ส.ค. หน้าเว็บจะขึ้นแถบเตือน "อีก … วันจะขึ้นปีงบ …" แถบจะเป็นสีแดงในวันที่ 30 ก.ย. และหลัง 1 ต.ค. ถ้ายังไม่ได้วางลิงก์
2. สร้าง Google Sheets ว่าง 2 ไฟล์ เช่น `รวมภารกิจต่างประเทศ ปีงบ71_ต้นทาง` และ `รวมภารกิจต่างประเทศ ปีงบ71_แสดงผล` โดยบัญชีที่ Deploy สคริปต์ต้องแก้ไขทั้ง 2 ไฟล์ได้
3. กดปุ่มบนแถบเตือน หรือปุ่ม **ไฟล์ข้อมูล** มุมขวาบน วางลิงก์ทั้ง 2 ไฟล์ แล้วกด **บันทึกลิงก์** ระบบจะตรวจว่าเปิดไฟล์ได้ แล้วสร้างแท็บให้เอง ไม่ต้องแก้โค้ดหรือ Deploy ใหม่
4. ตั้งแต่ 1 ต.ค. ตารางจะเปิดที่ปีงบใหม่เอง ถ้าต้องการดูหรือแก้ปีงบเก่า ให้เลือกปีงบที่แถบสรุปเหนือตาราง
5. ไทม์ไลน์และปฏิทินรายเดือนแสดงภารกิจของทุกปีงบรวมกัน ภารกิจที่อยู่คนละปีงบกับตารางจะมีเลขปีงบนำหน้า เช่น `70/12` คือภารกิจที่ 12 ของปีงบ 70

## แก้โค้ดฝั่ง Google ภายหลัง

วางโค้ดใหม่ใน Apps Script แล้วไปที่ **Deploy > Manage deployments** > ✏️ > Version: **New version** > Deploy
URL เดิมยังใช้ได้ จึงไม่ต้องแก้ config.js

## งานดูแลที่ทำได้ใน Apps Script

| ฟังก์ชัน | ใช้เมื่อ |
|---|---|
| `setAccessCode` | เปลี่ยนรหัสเปิดใช้งาน: แก้ `NEW_CODE` ในฟังก์ชันแล้วกด Run (คนที่เข้าอยู่แล้วใช้ต่อได้จนครบ 1 ชั่วโมง) |
| `renderNow` | วาดไฟล์แสดงผลของทุกปีงบใหม่ทันที |

ตัวตั้งเวลาที่ `setup` สร้างให้มีดังนี้
- วาดไฟล์แสดงผลใหม่ทุก 1 นาที ถ้ามีการแก้ไขที่ยังไม่ได้วาด (ปกติหน้าเว็บสั่งวาดเองหลังแก้ไขประมาณ 4 วินาที)
- ลบประวัติการแก้ไขที่เก่ากว่า 1 ปี ทุกวันเวลา 02:00
